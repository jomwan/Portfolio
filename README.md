# 🚀 Premium Data Science Portfolio

A high-performance, interactive Next.js 15 portfolio designed for Data Professionals. Featuring a liquid-glass aesthetic, neural network backgrounds, and full bilingual support.

## ✨ Features

- **Liquid Glass Navigation**: Smooth, theme-aware floating navbar with scroll-tracking.
- **Bilingual (EN/TH)**: Complete internationalization system with persistent language state.
- **Theme-Aware UI**: Seamless transitions between premium dark mode and elegant light mode.
- **Neural Background**: High-performance canvas-based particle system that reacts to themes.
- **Mobile First**: Fully responsive design for all screen sizes.
- **Tech Stack**: Next.js, Framer Motion, Tailwind CSS, Lucide Icons, and `next-themes`.

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `src/components`: UI modules (Hero, Navbar, NeuralBackground, etc.)
- `src/lib/i18n`: Translation dictionaries and LanguageContext.
- `src/app`: Next.js app router and global styling.
